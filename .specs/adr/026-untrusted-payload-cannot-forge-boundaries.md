# ADR-026: 不可信载荷不得伪造工件结构边界（写入侧转义）

- **状态**: 已接受（2026-09-18）
- **来源 change**: `l3-review-defects-2026-09`
- **关联**: ADR-010（内容标记）、ADR-025（前轮反馈注入）、ARCHITECTURE §4.1

## Context

`INDEPENDENT-REVIEW-<N>.md` 是**混装文件**：它同时包含
① flow-kit 自己写的**结构**（`## L2 盲审` / `## L3 重审` 标题、`L3_artifact_hash:` 元数据、
`<!-- /L3-SECTION -->` 标记）与 ② 外部模型的**原文载荷**（`_l3_call_api` 返回的原始文本，
可能是多行 markdown，包含任意行首 `## ` 标题甚至代码围栏 `` ``` ``）。

任何"从文件里切出某一段"的逻辑都必须判定段边界。本 change 的 `l3-review-defects-2026-09`
实测证明：**纯读侧的边界启发式会被载荷穿透，且是被生产写入路径穿透**，共三代：

| 代 | 读侧规则 | 穿透载荷 | 后果 |
|---|---|---|---|
| G1 | 只排除「引号开头的行」（免疫 L3 的 JSON 键） | 载荷里一行**非围栏**的 `**Verdict**: pass` | L3 的结论冒充 L2 的结论（报告 §B1 的原始故障） |
| G2 | 改按「L3 段行区间」排除，区间 = 到下一个 `^## ` 标题 | 载荷里一行 `## 附录：发现明细` | 区间提前收口，其后正文回流 L2 层 |
| G3 | 改「取范围内**最后一个**标记行」 | 载荷里 `## 附录…` + 更靠后的伪 `## L3 盲审（引用）` | 两个 span 之间留出**空洞**，空洞内容不被排除 |

三代都由 L2 独立盲审在**生产写入路径**（`_l3_parse_result` → `fk_extract_l2_verdict`）上复现，
且 G3 同时让 §B2 的"逐轮累积污染"复发（`^## L3 ` 恒为 2）。

可一般化的结论：**只要边界判定依赖"内容里哪一行看起来像标题/标记"，
载荷就总能造出一行来满足该条件**。读侧加固是无界的军备竞赛。

## Decision

**把不可信内容在写入时变成结构上不可能伪造边界的形式。**

`l3-section.sh` 导出**唯一入口** `_l3_escape_payload`，对载荷中**行首**匹配 `## `、
`<!-- /L3-SECTION -->` 或围栏 ``` 的行前插一个反斜杠：

```bash
_l3_escape_payload() {
  printf '%s\n' "$1" | sed -E 's~^(## |<!-- /L3-SECTION -->|```)~\\\1~'
}
```

围栏行也在范围内：`_l3_extract_prior_findings` 靠 ``` 切换 `in_json`，载荷里一个多余的 ```
会让围栏失同步，把其后的 L2 段误判为"仍在 JSON 内"，使前轮发现提取退化（设计期 L2 盲审 R2）。

**凡把模型/外部内容写进 `INDEPENDENT-REVIEW-<N>.md` 的写入方都必须调用它**。
当前有 **2 个载荷写入方**：① `l3-api.sh::_l3_parse_result`（L3 载荷）、
② `l2-detect.sh::l2_dispatch_agent`（**L2 载荷**，PreToolUse 生产路径）。
> 设计期 L2 盲审的 Critical 正是"只转义了 ①"：② 的载荷里一行 `## L3 盲审（引用…）`
> 会被判为 L3 段起点，随后 `_l3_strip_sections` 把该行到真标记之间的 **L2 报告正文一并切除**。
> 故转义必须是**契约**而非某处的一行代码；`B2-R8` 用跨文件断言守护。

**判据补强（设计期 L2 复审 N1）**：段起点除 `^## L3 (盲审|重审)` 外，还要求
**上方最近非空行为 `---`** —— 三个写入方自项目起源起就固定输出「空行 + --- + 空行 + 标题」
（`_l3_parse_result` / `l3_write_timeout_done` / `l3_write_bypass_done` 同款 preamble），
语料实测：**98 份工件共 129 个 L3 标题，129/129 上方最近非空行为 `---`**（无例外）。

这一条关掉的是**转义覆盖不到的第三个写入路径**：主 agent 按 L2 固化指令把子 agent 的
报告**贴进**工件（`L2-blind-review.md`：「你的报告由主 agent 贴进 … 的「L2 盲审」段」）。
贴入是 Write/Edit，不经任何转义函数；若 L2 报告正文里引用一句 `## L3 盲审（…）`，
读侧会把它当 L3 段起点，随后 `_l3_strip_sections` 把其后的 L2 正文整体切除。
`---` 判据使这类引用（上方无 `---`）不再被误判。

配套：

1. **标记仍是权威边界**：写入方三处（`_l3_parse_result` / `l3_write_timeout_done` /
   `l3_write_bypass_done`）在段尾落 `<!-- /L3-SECTION -->`（ADR-010 的"内容标记"方向）。
2. **读侧与写侧共用同一判定**：`l3-section.sh::_l3_section_spans` 是**唯一**的段区间来源，
   读侧（`_fk_l2_scope`）与写侧（`_l3_strip_sections`）都消费它（L-031）。
   区间规则保留为**纵深防御**：段终点 = 「本段起 → 下一个真实 L3 标题（或 EOF）」之间的
   **最后一个**标记行；无标记（历史工件）回落到「下一个 `## L2 ` / `## 主 agent ` / `## L3 ` 或 EOF」。
3. **依赖缺失不得 fail-open**：`_l3_section_spans` 不可用时，读侧做**保守排除**并打 WARNING，
   而不是"不排除任何东西"（后者会让 §B1 原样复活且零告警）。

## Consequences

**正面**

- **收敛**：三代穿透在同一机制下同时关闭。**经 `_l3_escape_payload` 写入的**载荷无法再造出
  以 `## ` 或标记字面量开头的行，故边界判定不再依赖"猜"。
- **不存在的「顺带收益」（设计期 L2 三审 R2 更正）**：本 ADR 初稿曾写「载荷里行首的
  `**Verdict**: x` 因前导 `\` 不再命中锚定正则」。**该句为假** —— 转义集只有
  `## ` / 标记 / 围栏三种**结构信号**，`**Verdict**:` 是**内容**、不在其中。
  而且它**不应**被转义：`_l3_escape_payload` 也服务 L2 载荷，而 L2 报告末尾正是
  `**Verdict**: pass|fail`，转义它会直接废掉 §B1 的提取。已删除该表述。
- 与 ADR-010 同向：都是"用显式内容标记取代隐式启发式"，本 ADR 补上"标记本身也可被伪造"这一层。
- 历史工件零影响：无标记 + 未转义的旧文件走标题法兜底，语料实测（224 份）取值分布不变
  （仅 8 份因"限定 L2 层"由有值变空，与转义无关）。

**负面 / 需接受**

- **落盘载荷与模型原文逐行不再完全一致**（行首多一个 `\`）。这是本 ADR 唯一实质代价。
  **该代价须如实陈述（设计期 L2 四审 R3 更正）**：载荷位于 ```json **围栏内**，
  而 markdown **不在围栏内解释转义** —— 故 `\##` 对读者**是可见的**，并不会"渲染回 `##`"；
  本 ADR 初稿写的"人读语义不变"**不成立**。真实的代价是：定稿落盘载荷与模型原文
  有可见差异（行首多一个 `\`）。仍判定可接受的理由改为三条：
  ① 转义只作用于行首的三种结构信号，其余内容逐字节不变；
  ② 差异是**单调可逆**的（去掉行首 `\` 即原文），不需要语义推断；
  ③ 载荷本就带 boilerplate 前缀与围栏包裹，"落盘内容 = 模型原文"在本项目中从来不是严格承诺。
- **无标记历史工件的兜底边界仍可被"转义前写入"的内容穿透**（范围已收紧，语料 1 份命中形态、
  0 份实际翻转）。这是兼容路径的固有残余，登记 MINOR-DEFERRED M7。
- **残余风险（设计期 L2 三审 R1 实测 · 必须显式承认）**：`---` preamble 判据**也是内容条件判据**，
  而本 ADR 的 Context 自己就写了"只要边界判定依赖内容里哪一行看起来像标题，载荷就总能造出一行
  来满足该条件"。实测：贴入内容里出现「`---` + 引用 `## L3 盲审（…）`」的引用块即产生伪 span，
  `_l3_strip_sections` 会删掉其后的 L2 正文（含 L2 自己的 `**Verdict**:` 行），
  且 `fk_extract_l2_verdict` 在此之前就已返回空。**即该判据只收窄窗口，不构成保证。**
  真正的收敛手段是把贴入路径也纳入转义契约 —— 贴入不经 hook，故落在
  `L2-blind-review.md` 文件写入约束第 4 条（已加）；
  **PreToolUse 可执行拦截（2026-09-18 已交付，不再是 v2）**：`_gate_is_unescaped_l3_paste`
  （`flow-kit-bundle/hooks/pre-tool-use/`）对「行首 `## L3 (盲审|重审)` + 上方最近非空行为 `---`
  + 其后再无 `<!-- /L3-SECTION -->`」的写盘内容 `exit 2`；豁免子系统自写块与已转义引用
  （回归 B9-R1..R6）。**仍存的边界**：绕过 PreToolUse 的写入通道（如 `Bash` 重定向）不在拦截内。
- **不设"零命中则放宽判据"的兼容回退**（设计期 L2 复审 N1）：回退会**正好在最需要判据时失效** ——
  文件里没有真 L3 段时，贴入的伪标题会被回退路径认成真段（`B2-R11` 实测）。
  代价是：**缺 `---` preamble 的 L3 段不再被识别**。语料 129/129 满足，故实测零影响；
  该边界由 `B2-R12`（≥50 份带 L3 标题的工件全部识别成功）守护。
- 未来若有新写入方落载荷而忘记转义，会静默 reintroduce 该族缺陷。
  **缓解**：转义表达式与标记字面量一起进入 § 9.5 建议的禁动清单；
  回归用例 `B1-R16/R18~R24`、`B2-R1/R2/R6/R7` 全部走生产写入路径。

## Alternatives considered

| 方案 | 否决理由 |
|---|---|
| 继续加固读侧启发式 | 已被实测穿透三代；可证明无界（载荷总能造出满足条件的行） |
| 用 `L3_artifact_hash:` 行当边界 | 该行是**可选**字段（无 artifact 时不写），不能作权威边界 |
| 让解析 fence-aware（忽略围栏内的标题） | 围栏本身可被载荷提前闭合（实测），且载荷外的 boilerplate 仍可被伪造 |
| 把 L3 结果存到独立文件 | ADR-010 已锁定结果落 `## L3` 段 + hash 元数据行；另起载体会破坏既有消费者（`_l3_check_rerun`、`flow-kit-resume`、L2/L3 同文件对照）的契约 |
| 用带 nonce 的标记 | 需在读取时知道 nonce → 又需一处可信存储；复杂度与收益不成比例 |
