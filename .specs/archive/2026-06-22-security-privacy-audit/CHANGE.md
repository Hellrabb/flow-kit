## Why（为什么做）

即将把 flow-kit 仓库 push 到**公开远程仓库**（GitHub public）。一旦公开，所有历史提交中的敏感信息将不可逆暴露。必须在 push 前对整个仓库做一次地毯式安全审查，确保：
- 零硬编码密钥/Token/密码
- 零内部路径/个人目录泄露
- 零个人信息（邮箱、手机号等）
- 零命令注入/路径遍历风险
- 零第三方 API 端点泄露

目标受众：公开互联网上的任何人。标准：最高（公开仓库）。

## What（做什么）

对仓库全部文件（`.sh`、`.json`、`.md`、`hooks/`、`lib/`、配置、脚本、注释、git 历史）做一次全面的安全与隐私泄露审查。覆盖六大风险维度：

1. 🔑 **硬编码凭证** — 密钥、Token、密码、API Key
2. 🏠 **内部路径/IP 泄露** — 个人目录、内网地址、`127.0.0.1`、内部域名
3. 📧 **个人信息** — 邮箱、手机号、真实姓名、身份信息
4. 🐚 **注入与路径遍历** — 命令注入、不安全的 `eval`、路径遍历漏洞
5. 🌐 **第三方端点泄露** — 未脱敏的 API endpoint、内部服务 URL
6. 📜 **Git 历史残留** — 历史提交中的敏感信息（即使已删除文件）
