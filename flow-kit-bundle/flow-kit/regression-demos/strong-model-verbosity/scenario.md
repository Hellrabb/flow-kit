# Scenario · strong-model-verbosity（AC-7 · 强模型不过度啰嗦）

**背景**：加固（L1-L3）若表现为重复唠叨（每步复述 goal / 每操作 checkpoint / 冗余自检），会让强模型上下文膨胀、注意力分散，**反而增加幻觉**。本 demo 守住"加固不反噬强模型"的底线。

**检查项**（静态 · D4 脚本模拟）：
1. 加固有意识地限定触发点：4-dev「非每操作」、GO「仅入场」（不是无差别全局强制）
2. gate 是填空式（0-change / 1-requirement）：刚性结构，强模型填空不啰嗦
3. 反向：加固段不得出现「每步复述 goal」「每次操作 checkpoint」类无条件唠叨

**未覆盖**：定量阈值（强模型基准任务输出 token/turn 增量 < 20%）需真跑强模型，留 v2 自动化。本次靠静态检查（护栏设计是非啰嗦的）+ 人工定性（实际使用中强模型未感知变啰嗦）。
