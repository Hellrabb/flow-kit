# 语义（与 nfr-portability-baseline.txt 同族的 ratchet 基线，但对象是「判据形态」）：
#   - 本文件 = 路径隐私门禁（flow-kit-bundle/flow-kit/reference/check-path-privacy.sh）
#     的判据形态基线；**不是允许清单**（允许清单 = path-privacy-allowlist.txt，

#   - 只存三类内容：通用 PAT / 占位形态 / 本机字面量 sha256 对账行。

#   - 对账（供 T16「历史重写」与波末审计）：在同一台机器上按下方派生规则重算

#     或远端已变，须重算更新本文件并在 change 档过账。历史重写侧可用候选字面量
#     的 sha256 反查本基线，确认清理目标与基线口径一致。
#   - PAT / 占位表只在门禁源码演进时随动更新本文件（对账行同时重算）。
